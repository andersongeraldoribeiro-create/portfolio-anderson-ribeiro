# Deploy na Vercel

## Teste local

```bat
cd caminho\para\portfolio-anderson
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.

## Build local

```bat
npm run build
```

## GitHub

Configure o Git para a conta principal antes de novos commits:

```bat
git config --global user.name "Anderson Ribeiro"
git config --global user.email "andersongeraldoribeiro@gmail.com"
```

O GitHub principal usado no portfólio é:
`https://github.com/andersongeraldoribeiro-create`

## Vercel

Importe o repositório no painel da Vercel e mantenha as configurações padrão de Next.js. Não são necessárias variáveis de ambiente para a versão atual do portfólio.
