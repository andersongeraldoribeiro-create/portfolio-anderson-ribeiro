# Anderson Ribeiro — Portfólio Premium V4

mium v3

Portfólio profissional em Next.js, pensado para apresentação de experiência em redes, infraestrutura e desenvolvimento, com foco em oportunidades remotas/home office.

## Direção visual

- Estética grafite + esmeralda
- Hero assimétrico com tipografia grande
- Foto original de Anderson Ribeiro usada diretamente, sem alteração facial
- RotaObra e NetVision PRO em destaque
- Experiência, formação, stack, disponibilidade remota e contato
- Layout responsivo para desktop, tablet e mobile

## Rodando localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Validação

O projeto foi validado com ESLint e TypeScript (`tsc --noEmit`). O build completo em ambiente Linux pode tentar baixar o SWC correspondente; no Windows, rode `npm run build` após `npm install`.

## Deploy na Vercel

1. Suba o projeto para o GitHub.
2. Na Vercel, escolha **Add New > Project**.
3. Importe o repositório.
4. Framework: **Next.js**.
5. Build Command: `npm run build`.
6. Deploy.
